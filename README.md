# letsstudy — 독서실 졸음 깨우미

독서실에서 공부하다 졸면 알람으로 깨워 주는 웹페이지예요.

## 기능
- **눈 감김 감지**: 카메라로 눈이 감긴 시간을 재서, 설정한 시간(1.5 / 2.5 / 4 / 10초) 넘게 감고 있거나 고개를 숙여 얼굴이 사라지면 알람이 울려요. 영상은 기기 밖으로 나가지 않아요.
- **랜덤 숫자 확인**: 예고 없이 숫자 맞추기가 뜨고, 제한 시간 안에 못 맞추면 알람이 울려요.
- 알람은 같은 숫자 버튼을 눌러야 꺼져요. 안드로이드는 진동도 같이 와요.
- 카메라 화면은 숨길 수 있고(감지는 계속돼요), 소리 크기를 조절할 수 있어요.
- **이어폰에서만 소리 내기**: 이어폰이 확인되지 않으면 소리 없이 진동과 화면 깜빡임으로만 깨워요. 이어폰 확인은 브라우저가 알려 주는 기기 이름으로 하기 때문에, 아이폰처럼 이름을 알려 주지 않는 환경에서는 늘 '확인 안 됨'으로 처리돼요.

## 쓰는 법
1. 저장소 Settings → Pages에서 Branch를 `main`으로 정하고 저장해요.
2. 생긴 `https://raina-e.github.io/letsstudy/` 주소를 폰 크롬에서 열어요.
3. 카메라를 허용하고, 폰을 세워 얼굴이 정면으로 들어오게 둔 뒤 공부 시작을 눌러요.

화면이 꺼지거나 다른 앱으로 넘어가면 멈추니까 페이지를 띄워 둔 채로 써 주세요.
